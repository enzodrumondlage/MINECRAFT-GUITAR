# Minecraft Guitar Legends (Fabric 1.20.1)
## Estado: protótipo inicial, não é o mod completo
Implementados: 16 guitarras com texturas PNG e crafting, registro no inventário e tela de pista com F G H J K (Shift fecha).
Ainda faltam: áudio, editor, sincronização, notas, pontos, dificuldades, cenários e testes dentro do Minecraft.

## Como compilar
Instale JDK 17 e Gradle 8.x. Execute `gradle build` na raiz.
Este pacote não inclui o Gradle Wrapper nem um JAR compilado; compilação não foi testada aqui.
